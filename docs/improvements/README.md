## 우선순위 표기

모든 개선 항목은 다음 우선순위로 분류됩니다:

- **P0 (필수)**: 프로젝트 기본 동작 또는 품질 기준을 위해 반드시 필요한 항목
- **P1 (중요)**: 학습 목적 달성 또는 실무 수준 완성도를 위해 권장되는 항목
- **P2 (권장)**: 완성도를 높이거나 추가 학습 가치가 있는 항목

## 작업 진행 방식

### 1. Phase별 순차 진행
- Phase 1부터 순서대로 진행 (병렬 작업 가능)
- 각 Phase 완료 후 다음 Phase 시작

### 2. 모듈별 독립 작업
- 각 모듈은 독립적으로 작업 가능
- 단, 전체 프로젝트 개선사항(Phase 1)을 먼저 진행 권장

### 3. 우선순위 준수
- 각 모듈 내에서 P0 → P1 → P2 순으로 진행
- P0를 완료해야 해당 모듈이 "학습 가능한 상태"

## 문서 업데이트 정책

### 언제 업데이트하는가?
- 개선 항목 작업 완료 시: 해당 항목을 체크 또는 제거
- 새로운 개선 사항 발견 시: 적절한 모듈 문서에 추가
- 작업 우선순위 변경 시: 해당 문서 및 roadmap 업데이트

### 누가 업데이트하는가?
- 작업자가 직접 업데이트
- PR 리뷰 시 문서 업데이트 여부 확인

### 형식
- 작업 완료 항목: `- [x] 항목명` 또는 항목 삭제
- 날짜 기록: 필요시 `(완료: YYYY-MM-DD)` 추가
