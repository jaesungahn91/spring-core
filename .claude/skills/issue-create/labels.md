# Labels

## Type (필수)
- `type: bug` — 버그 수정
- `type: feature` — 신규 기능
- `type: enhancement` — 기존 기능 개선
- `type: refactor` — 동작 변경 없는 코드 구조 개선
- `type: test` — 테스트 추가/수정
- `type: docs` — 문서
- `type: chore` — 빌드, 의존성, 설정, CI/CD
- `type: security` — 보안 취약점
- `type: performance` — 성능 개선

## Module (코드 변경 시 필수)
- `module: security-jwt`
- `module: data-jpa`
- `module: rest-docs`
- `module: data-mongodb`
- `module: batch`
